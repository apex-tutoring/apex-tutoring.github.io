# Apex Tutoring — prototype

This folder contains a single-page website prototype. It is **not published**. The shop cart is a visual demo only; there is no checkout, payment processing, order storage, inventory, or booking system.

## Preview the site

1. Keep `index.html` and this file together in the same folder.
2. Double-click `index.html` to open it in a web browser.
3. After editing and saving the file, refresh the browser tab to see your changes.

## Edit the site

- Open `index.html` in Visual Studio Code (recommended) or a plain-text editor.
- Use Find (`Ctrl+F` on Windows / `Cmd+F` on Mac) to search for the words you want to change, such as `Meet your tutor`, `Elementary Math`, `TBD`, or `Math Puzzle Pack`.
- Replace the draft wording with details that have actually been decided.
- Save the file, then refresh the browser.

Do not replace the `TBD` prices or publish course cards until the details are confirmed. The preview banner is intentionally visible so nobody mistakes the draft for a live business website.

## Business decisions to make before launch

1. **Tutoring scope (selected):** Grades 3–5, with Elementary School Math and Early Middle School Math foundations. Keep the topic list realistic and teach only material you can confidently explain.
2. **Tutor introduction:** write a short, teaching-focused introduction. Use only a parent/guardian-approved first name or tutor name; do not publish your school, home location, personal schedule, or private contact details.
3. **Session format and pricing:** decide the session length first, then the rate, individual vs. group format, and basic cancellation expectations. Have a parent/guardian review the plan.
4. **Shop products:** choose a small number of specific math resources and focus fidgets, check product quality and sourcing with a parent/guardian, and calculate a price that accounts for the full cost.
5. **Launch and safety:** a parent/guardian should oversee publishing, domain/hosting accounts, customer messages, any meeting arrangements, store setup, and payments. Add a monitored, approved contact method only after that is arranged.

## Current draft content

- Planned tutoring scope: Grades 3–5; Elementary School Math and Early Middle School Math foundations. Specific topics should match the student’s level and the tutor’s confidence.
- Pricing: not set.

## Student & Parent Portal prototype
The page now includes a shared Student & Parent dashboard preview and a Teacher tools preview. Use the buttons in the Student Portal section to switch between them. The teacher form adds a sample progress note to the visible dashboard for this browser session only.

**Not production-ready:** There is no real sign-in, password handling, database, access control, or cross-device sync. Do not enter real student information. Before launch, a parent/guardian and a qualified developer should set up secure authentication, role-based permissions (teacher-only editing), protected storage, and an appropriate privacy process.
